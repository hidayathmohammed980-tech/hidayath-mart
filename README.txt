HIDAYATH MART - FREE SHOPPING APP PROTOTYPE

How to use:
1. Open index.html in Chrome/Edge to test the app.
2. It works on mobile and desktop.
3. Products, cart and wishlist are demo data stored in the browser.
4. To turn this into a real store, add a database, admin panel, real product images, user login, payment gateway and delivery/order APIs.

This is a free prototype and does not process real payments.
